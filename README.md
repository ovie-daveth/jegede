# Micheal Jegede — Engineering Portfolio
A full-stack engineering portfolio with authenticated project management, durable D1 project records and R2 file uploads.

## Administration
Visit /admin and sign in with ChatGPT using an email in the ADMIN_EMAILS runtime setting (default: michealjegede3@gmail.com). All write APIs authorise this allowlist server-side. Add/edit projects, select year, tools, category and description, upload multiple files, save a draft or publish. Delete files or projects with confirmation.

## Media
Uploads support common video, audio, image, PDF, CAD, document and archive extensions; 90 MB per file. MP4/WebM are recommended for in-browser video playback. Files that require native engineering software are downloadable. Range responses support video seeking. SVG, HTML and executable uploads are excluded.

## Content
No candidate design files were supplied. The landing-page drawing is explicitly illustrative. The AdBlue project summary uses only the candidate's supplied statement; no software, year, detailed scope or outcomes are invented. Upload actual files and project details through the admin dashboard.

## Access
New Sites are private by default. Admin authorisation is separate from site-wide audience settings. To launch publicly for employers, change the Sites audience to public; the admin endpoints remain allowlist-protected.
